# AI Usage
AI was used as a development assistant throughout this project.
- Helped in understanding the requirements, dataset, and the given simulation code.
- Helped scaffold the initial Express + TypeScript backend structure.
- Assisted in writing individual functions such as SQLite import scripts, policy rules, queue handling, and metrics aggregation.
- Helped debug runtime issues including SQLite path resolution, queue behavior, and TypeScript typing errors.
- Assisted in designing the policy engine architecture so that new rules (such as the Day 2 regulator rule) could be added with minimal changes.
- Helped generate documentation, diagrams, and README content.
- Reviewed code for improvements and suggested refactoring for maintainability.
- Finally in documenting the `AI-USAGE.md`, `DECISIONS.md`, and `README.md` files.

All implementation decisions, integration, testing, and final code selection were performed by me.
